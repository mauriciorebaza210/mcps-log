### How-to (tools and gotchas)
- **Deploy the engine:** `npm run ee:deploy "<what>"` as its own command (as Tony). Tony login lost → `clasp --user tony login` in `email-engine/` in the background, `open` the URL, Mau signs in as antonio@.
- **Deploy the portal Apps Script:** only from `~/mcps-log` (full working branch) with `npm run gas:deploy` (pinned deployment). First `clasp pull` the live project into a scratch folder and diff file lists + contents (clasp branch trap). Mau's clasp login can expire (`invalid_rapt`): run `clasp login` in the background and `open` the URL.
- **Ship the portal:** commit on `feat/email-engine`, `git push origin feat/email-engine` and (with Mau's go) `git push origin feat/email-engine:main` (fast-forward; merge `origin/main` first if it moved). Bump `?v=` on changed files in index.html.
- **Engine status (public):** `curl -sL <engine /exec>` → version, owner, journal, `data_ss_id`.
- **Calling APIs without a session:** `npx -y vercel@65.14.0 curl "/api/email?op=…" --deployment <url>` (401 = loaded). Production: plain `curl https://mcps-log.vercel.app/api/email?op=read` → 401.
- **Vercel env:** never read values; `vercel env ls` for names. Adding: `printf %s "$VAL" | npx -y vercel@65.14.0 env add NAME production --sensitive` run inline (inside a shell function it failed). **Never `npx vercel env run -- …`** (npx ate `--` and deployed a stray project).
- **Engine data from Claude:** not readable without a portal session; ask Mau for a screenshot.
- **Vercel functions:** at the Hobby cap (12): new API work goes into `api/email.js` ops. Never `createRequire` in `api/`.
- **Screenshot harness:** `node email-engine/tools/ui-harness/fixture.mjs`, headless Chrome on `harness.html` (README). Params: `tab=`, `cmp=B|C`, `view=calendar`, `wiz=who|when|people|review` (+`nb=`, `mv=1` dumps batch-move counts), `drawer=step:<id>`, `dtab=templates`, `edit=text|html|preview` (+`pastefull=1`), `sglnew=`, `att=1`, `setup=…`, `seen=1`, `menu=1`, `tour=<chapter>&tstep=N`, `play=N` (+`ch=<chapter>`: clicks through the tour to step N), `rq=1|pick|pointing|sent`, `sender=1`, `slow=1`. Use `--virtual-time-budget=40000` for `play`.
- **Guards:** `tests/email-engine-actions.test.js` (every engine admin action routed in `api/email.js` ADMIN_CAP or relayed); vm-loaded tests need `JSON.parse(JSON.stringify(x))` before deepEqual.
